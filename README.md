# TEC KPI Performance Tracker

Initial prototype for tracking institutional performance across production, training, and research and development.

## Production units
- Fashion
- Leather
- Graphics
- Paint
- Consumables
- Smart Farm
- Aquaculture

## Current status
This is a front-end prototype. Reports are held temporarily in browser memory and will disappear when the page is refreshed. There is no authentication, shared database, or enforced access control yet.

## Planned architecture
- Frontend: HTML, CSS and JavaScript
- Database and authentication: Supabase free tier
- Security: database-enforced Row Level Security (RLS)
- Workflow: Draft, Submitted, Approved and Returned
- GitHub: source-code version control

Do not enter confidential or official institutional data into this prototype.
